# Traces

Hand traces made with `../tracer.html`, one `NAME.trace.json` per image (Save in the tracer). Each holds the points placed on the image, the curve through them, each plane's calibration to mm and the controls' misses (`derived`). The images themselves (video frames, other people's photographs) stay outside the repository, in `$MC_VIDEO`; the trace names its image and its source.

Traces made on the owner's phone, in the claude.ai copy of the tracer (Edge Tracer, <https://claude.ai/artifact/Ju3PQ8QErkH3fdRWZcSLjq>), arrive in that artifact's store (`traces/ID`, the `.trace.json`'s text in its `json` field); Claude saves each here under the same name, as for a trace saved on the computer.
